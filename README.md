# 👤 Random User Generator

A simple **Random User Generator** made using **HTML, CSS, JavaScript and API**.

Click the button to fetch and display a random user's information.

## ✨ Features

- 👤 Random user details
- 🔄 New user on button click
- 🌐 API integration
- 🖼️ User profile image
- 📱 Simple UI

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Random User API

## 🚀 How to Run

Open the `index.html` file in your browser.
